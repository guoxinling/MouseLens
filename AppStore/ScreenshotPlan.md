# MouseLens Screenshot Plan

## Goal

Create honest Mac App Store screenshots from the real app UI. Avoid marketing-only compositions. Screenshots should show the actual recording and editing workflow.

## Proposed Set

### 1. Record From The Toolbar

Show the compact recording toolbar with Screen/Window target, audio toggles, aspect ratio, and Record button.

Caption idea: `Record screen or window demos`

### 2. Finish From Floating Controls

Show the floating recording toolbar during capture with pause/finish controls.

Caption idea: `Control recording without leaving the flow`

### 3. Preview Immediately

Show the editor with playable preview, cursor reconstruction, and click feedback.

Caption idea: `Preview the result right away`

### 4. Refine Zoom

Show the Zoom Track with Auto and Manual segments.

Caption idea: `Tune automatic and manual zoom moments`

### 5. Style The Frame

Show background swatches, padding, corner radius, and the preview canvas.

Caption idea: `Style clean walkthrough videos`

### 6. Export MP4

Show the export panel or exported result state.

Caption idea: `Export polished MP4s`

## Capture Notes

- Use a clean desktop.
- Use a short demo project with visible cursor/click/zoom behavior.
- Keep screenshots consistent in window size and visual theme.
- Avoid showing private files, usernames, tokens, terminal secrets, or internal project paths.
- Capture the actual app UI; do not fake features that are not implemented.
