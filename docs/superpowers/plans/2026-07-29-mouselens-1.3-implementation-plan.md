# MouseLens 1.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MouseLens 1.3 around Apple Speech captions, editable caption export, Notes/teleprompter support, cursor style customization, and Simplified Chinese localization.

**Architecture:** Add captions, Notes, cursor styling, and localization as independent product layers on top of the existing recording, preview, and export architecture. Captions and cursor styles must feed the existing shared composition path so preview, MP4 export, and GIF export remain visually aligned. Apple Speech is the only transcription provider in 1.3, behind a provider protocol that can accept cloud or AI providers later without changing editor/export surfaces.

**Tech Stack:** Swift, SwiftUI, AVFoundation, Speech framework, existing MouseLens render/export pipeline, XCTest, Xcode project configuration, `.xcstrings` or existing localization resource pattern after repo inspection.

## Global Constraints

- Do not record the native cursor into the source video.
- Do not couple cursor motion directly to camera motion.
- Do not introduce separate preview-only, MP4-only, or GIF-only visual composition paths.
- Do not add cloud dependencies to the default recording/export workflow.
- Use Apple Speech local/system transcription for 1.3; do not add DeepSeek, OpenAI, Whisper cloud, or any third-party ASR service in 1.3.
- Use `Notes`, not `Prompt`, in UI copy.
- The user will provide final cursor visual assets; implementation should create placeholder plumbing only until assets arrive.
- Add Simplified Chinese for core app UI; Traditional Chinese is out of scope for 1.3.
- Preserve existing Screen and Window cursor/zoom behavior.
- Test only the canonical app when doing real app validation: `/Users/guoxl/Documents/Playground/MouseLens/.LocalTestApp/MouseLens.app`.
