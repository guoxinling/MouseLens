## Description

MouseLens is a focused macOS recording tool for creating polished screen demos quickly.

Record a screen or window, then review the result in the built-in editor. MouseLens helps you turn ordinary interaction recordings into clear product walkthroughs with smooth zoom, visible cursor movement, click emphasis, visual backgrounds, trimming, presenter camera, and flexible export.

Key features:

- Screen and window recording
- Cursor and click emphasis for clearer tutorials
- Automatic zoom moments based on interaction
- Manual zoom segments with editable focus and timing
- Presenter camera bubble with adjustable position, size, and corner radius
- Built-in wallpaper backgrounds, padding, and rounded-corner controls
- Timeline trim controls
- MP4 export for high-quality videos
- GIF export for short shareable clips
- Local-first recording workflow

MouseLens is intentionally narrow: it helps you turn interaction recordings into clear product walkthroughs without a heavy editing workflow.

## Review Notes

MouseLens records the screen or a selected window using macOS Screen Recording permission. It can optionally include microphone audio, system audio, and a camera presenter bubble. Pointer activity is used locally to show cursor movement, click feedback, and zoom focus in preview/export.

Suggested review flow:

1. Grant Screen Recording permission when prompted.
2. Grant Microphone permission if testing microphone audio.
3. Grant Camera permission if testing the presenter camera bubble.
4. Start a short screen or window recording.
5. Finish recording from the floating recording toolbar.
6. In the editor, play the recording, adjust background, padding, zoom, or presenter bubble settings if desired, then export MP4 or GIF.

No account is required.
