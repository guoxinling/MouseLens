## 一、中文名称推荐

### 推荐方案：妙镜

| 维度 | 说明 |
|------|------|
| **名称** | 妙镜 |
| **拼音** | Miào Jìng |
| **字数** | 两字，简洁有力 |
| **含义** | 「妙」= 巧妙、智能（呼应 Smart Zoom 自动镜头语言），「镜」= 镜头、聚焦（呼应 Lens 放大和光标跟随） |
| **谐音联想** | 与「妙境」同音，暗示成片效果精妙自然 |
| **检索性** | 双字词，输入方便，记忆成本低 |

#### 为什么选「妙镜」

1. **高度概括产品核心**：妙 = 智能自动（Smart Zoom、自动镜头），镜 = 录屏镜头（录制 + 放大焦点）
2. **二字名简洁**：符合 macOS 工具类 App 的命名习惯
3. **正向联想**：「妙」字自带品质感和巧思，「妙境」暗示成品精致
4. **无负面歧义**：不会和现有品牌或产品类别混淆

### 备选方案

| 名称 | 拼音 | 释义 | 优劣势 |
|------|------|------|--------|
| **录镜** | Lù Jìng | 录 = 录制，镜 = 镜头聚焦 | 更直白功能化，但缺少品牌辨识度 |
| **聚录** | Jù Lù | 聚 = 聚焦放大，录 = 录制 | 功能指向明确，但「聚录」与「巨鹿」同音，可能产生无关联想 |
| **光标镜** | Guāng Biāo Jìng | 光标 + 镜头 | 三字偏长，直译感较强 |

### 描述

妙镜是一款专注演示视频制作的 macOS 录屏工具。录制屏幕或窗口后，在内置编辑器中即可获得智能聚焦、光标强调和自动缩放效果——无需手动剪辑，录完就有「做过后期」的观感。

**核心功能：**

- **屏幕与窗口录制**——自由选择全屏或指定窗口为录制目标
- **智能聚焦镜头**——根据操作自动生成平滑的缩放和镜头移动，也可手动添加聚焦段落
- **光标与点击强调**——光标轨迹清晰可见，点击有视觉反馈，让教程和演示更易懂
- **讲解人头像**——录制时叠加摄像头画面，可调节位置、大小和圆角
- **语音生成字幕**——基于端侧语音识别自动生成可编辑字幕，支持在 MP4 和 GIF 导出时烧录
- **多种光标样式**——白箭头、黑箭头、高对比度、柔和指针、聚焦圆点、指示手、魔法棒、猫爪等风格可选
- **内置背景与边框**——提供 20+ 渐变和纯色背景，支持内边距和圆角调节
- **时间线裁剪**——快速去除开头和结尾的冗余片段
- **MP4 高清导出**——适合产品发布、网站嵌入、文档教程
- **GIF 轻量导出**——适合更新日志、Issue 追踪、快速分享
- **中英文界面**——根据系统语言自动切换简体中文或英文

妙镜的定位是有意做窄：不做全功能视频编辑器，只做好「把屏幕操作变成清晰演示视频」这一件事。全程本地运行，无需注册账号。

**适用场景：**
- 产品经理录制新功能演示
- 独立开发者制作 App Store / Product Hunt 动图
- 教程作者制作操作教学视频
- 技术支持团队录制复现步骤
- 运营同学制作社媒产品介绍短视频

### 审核备注（Review Notes）

妙镜使用 macOS 屏幕录制权限录制屏幕或指定窗口。可选启用麦克风（用于录制讲解语音和生成字幕）、摄像头（用于讲解人头像叠加）。指针活动数据仅在本地使用，用于在预览和导出中重建光标轨迹、点击反馈和智能聚焦。

**建议审核流程：**

1. 授权「屏幕录制」权限
2. 如需测试语音字幕，授权「麦克风」权限
3. 如需测试讲解人头像，授权「摄像头」权限
4. 开始一段简短的屏幕或窗口录制
5. 通过悬浮录制工具栏结束录制
6. 在编辑器中播放录制内容，可尝试生成字幕、调整背景/内边距/缩放/讲解人头像/光标样式等参数
7. 导出 MP4 或 GIF

无需注册账号，所有数据存储在本地。

**权限说明文案（已在 Info.plist 中配置）：**

| 权限 | 中文文案 |
|------|----------|
| 屏幕录制 | 妙镜需要屏幕录制权限来录制您的屏幕或窗口内容。 |
| 麦克风 | 妙镜可以在录制时同步收录麦克风音频。 |
| 摄像头 | 妙镜可以在录制时叠加讲解人头像画面。 |
| 语音识别 | 妙镜使用语音识别从您的录制中生成可编辑字幕。 |

### 隐私政策说明

- **数据收集**：无。除非未来添加分析或崩溃报告功能。
- **与用户关联的数据**：无。
- **追踪**：否。

如果在后续版本中添加了遥测、崩溃报告、云同步、支付或账号功能，需重新确认以上隐私答案。

## 四、备选名称详细评估

### 方案 A：妙镜（推荐）

```
优势：
✅ 二字简洁，含义丰富（巧妙+镜头）
✅ 「妙」字自带品牌好感，暗示智能自动
✅ 谐音「妙境」，有品质联想
✅ 无竞品冲突

劣势：
⚠️ 首看可能不太直观（需配合副标题说明品类）
```

### 方案 B：录镜

```
优势：
✅ 功能直白（录制+镜头）
✅ 同为二字，简洁

劣势：
⚠️ 缺乏品牌温度和差异化
⚠️ 可能被误读为「录像」的变体
```

### 方案 C：聚录

```
优势：
✅ 含义贴切（聚焦+录制）
✅ 二字简洁

劣势：
⚠️ 与「巨鹿」同音，搜索时可能被干扰
⚠️ 视觉上没有「镜」字的品牌识别度
```

### 方案 D：瞄镜

```
优势：
✅ 「瞄」= 瞄准/光标指向，切合产品
✅ 「镜」= 镜头聚焦
✅ 通「妙镜」同音，便于口头传播

劣势：
⚠️ 「瞄」略带随意感，不如「妙」有品质感
```

### 方案 E：光标镜

```
优势：
✅ 含义完整明确（光标镜头跟随）

劣势：
⚠️ 三字偏长
⚠️ 直译感强，更像功能描述而非品牌名
```

## 五、最终建议

**首选：妙镜**，配合副标题「智能聚焦，录完即分享」或「录屏即演示」。

理由：在品牌感、记忆成本、功能表达三个维度上综合最优，且为后续品牌建设（官网、社交媒体、PR 稿）留出了足够的叙事空间。与原名 MouseLens 一样保持了「灵巧 + 聚焦」的双重含义。

如果更偏好直白功能性风格，**录镜**是稳妥的第二选择。
