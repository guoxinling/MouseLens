## Description

MouseLens is a focused macOS recording tool for creating polished screen demos quickly.

Record a screen or window, then review the result in the built-in editor. MouseLens rebuilds cursor motion from recorded pointer events and separates camera motion from the original video, so you can tune zoom, framing, padding, rounded corners, backgrounds, and trim before export.

Key features:

- Screen and window recording
- Cursor reconstruction and click feedback
- Automatic zoom moments based on interaction
- Manual zoom segments with editable focus and timing
- Timeline trim controls
- Background, padding, and corner radius controls
- MP4 export presets
- Local-first recording workflow

MouseLens is intentionally narrow: it helps you turn interaction recordings into clear product walkthroughs without a heavy editing workflow.

## Review Notes

MouseLens records the screen or a selected window using macOS screen recording permission. It can optionally include microphone and system audio. Pointer activity is recorded separately and used locally to rebuild cursor motion and camera zoom in preview/export.

Suggested review flow:

1. Grant Screen Recording permission when prompted.
2. Grant Microphone permission if testing microphone audio.
3. Start a short screen or window recording.
4. Finish recording from the floating recording toolbar.
5. In the editor, play the recording, adjust background/padding/zoom if desired, then export MP4.

No account is required.
